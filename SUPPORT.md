# Support

If you need help with this project, here are the best ways to get it:

1.  **Read the Documentation:** Check the `docs/` folder or the `README.md` for getting started guides and architecture deep dives.
2.  **Search Existing Issues:** Before opening a new issue, please search the existing [GitHub Issues](https://github.com/DARREN-2000/OCR-with-Handwritten-Recognition-and-Auto-Spelling-Correction/issues) to see if someone else has already reported your problem.
3.  **Open an Issue:** If you can't find an answer, open a new issue. Please provide as much detail as possible, including logs, error messages, and steps to reproduce.
