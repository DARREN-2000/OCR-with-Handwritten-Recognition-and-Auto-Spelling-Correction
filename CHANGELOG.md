# Changelog

## [1.0.0] — 2025-01-01

### Added
- Tesseract 5 OCR with LSTM engine
- NLTK tokenization pipeline
- Automatic language detection (EN, FR, DE, ES, PT)
- LanguageTool grammar and spelling correction
- Flask web interface with file upload
- REST API at `/api/v1/`
- Downloadable `.txt` output
- GitHub Pages static demo using Tesseract.js
- CI pipeline with GitHub Actions
- pytest test suite
