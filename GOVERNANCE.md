# Governance

This document describes the governance model for this project.

## Benevolent Dictator For Life (BDFL)

This project is currently governed by a BDFL model, where the original author(s) hold the final say in project direction and technical decisions.

## Maintainers

Maintainers are community members who have shown dedication to the project through sustained contributions, code reviews, and community support. They have commit access to the repository and can merge pull requests.

## Decision Making

Most day-to-day decisions are made through consensus on pull requests and issues. If a consensus cannot be reached, the maintainers will make a final decision.
