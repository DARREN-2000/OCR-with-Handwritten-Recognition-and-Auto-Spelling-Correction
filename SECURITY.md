# Security Policy

## Supported Versions

Only the `main` branch is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please DO NOT open a public issue. Instead, send an email to the repository maintainers.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you report a vulnerability, you may be eligible for public recognition once the issue has been resolved.
