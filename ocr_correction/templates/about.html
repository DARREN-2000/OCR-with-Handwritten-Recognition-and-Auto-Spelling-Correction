About This Project

This project implements an NLP-based automatic spelling correction system that processes scanned or handwritten documents end-to-end. It combines Tesseract OCR with an NLP pipeline (NLTK tokenization + LanguageTool language modeling) to deliver accurate text extraction and correction.

REST API

This system also exposes a versioned REST API at /api/v1/. Send a POST request with an image file and receive the extracted and corrected text as JSON. Visit the API endpoint for details.
